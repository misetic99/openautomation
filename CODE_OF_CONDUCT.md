# Code of Conduct

We want this project to be a welcoming place for everyone who works with industrial automation,
whatever their experience, background or employer.

## Expected behaviour

- Be respectful and assume good intent.
- Give and accept constructive feedback.
- Focus on what is best for the project and its users.
- Keep discussions technical and on topic.

## Unacceptable behaviour

- Harassment, insults, personal attacks or discrimination of any kind
- Publishing someone's private information
- Sharing confidential customer code or data
- Anything else that would be inappropriate in a professional setting

## Enforcement

Maintainers may remove comments, commits or issues that break these rules, and may temporarily or
permanently ban people who repeatedly do so. Report problems privately to the maintainers, using
GitHub's private reporting or the contact listed in the repository profile.

This Code of Conduct applies in all project spaces and when representing the project in public.
